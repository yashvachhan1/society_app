# empty_module_screen.dart

Mirrors `lib/features/common/screens/empty_module_screen.dart`.

**Purpose** — the placeholder every unbuilt module opens.

## What's inside

- `EmptyModuleScreen` (StatelessWidget) — `title` and `icon`. An app bar with
  the module name and a centred `EmptyState`: "Nothing here yet" plus
  "<title> will be available in a later release."

## Used by

`lib/main.dart` routes it for Payments, Notices, Complaints, Guests, Home
Services, Staff, Family and Vehicles.
