# detail_row.dart

Mirrors `lib/core/widgets/detail_row.dart`.

**Purpose** — a read-only label/value row inside a card: the standard way this
app displays a record's fields.

## What's inside

- `DetailRow` — `label`, `value`, `isLast` (drops the divider), `valueColor`
  (used to grey out placeholders like "Not added").

## Used by

Home screen (flat and society details) and profile screen (account and
membership details).
