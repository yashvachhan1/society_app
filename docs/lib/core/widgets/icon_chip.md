# icon_chip.dart

Mirrors `lib/core/widgets/icon_chip.dart`.

**Purpose** — a small pill with an icon and a label, used for metadata.

## What's inside

- `IconChip` (StatelessWidget) — `label`, `icon`, `color`. Renders a rounded pill
  with a 12% tint of `color`, a 13px icon and small bold text.

## Used by

Detail rows on cards (dates, categories, small facts).
