# info_banner.dart

Mirrors `lib/core/widgets/info_banner.dart`.

**Purpose** — a tinted strip that explains something at the top of a screen.

## What's inside

- `InfoBanner` (StatelessWidget) — `message`, `icon`, `color`. Rounded container
  with a 12% tint of `color`, the icon on the left and the message beside it.

## Used by

`services_screen.dart`, `alerts_screen.dart` and other screens that need a short
explanation before the content.
